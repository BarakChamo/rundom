# HTML tree-construction kernel

`run-dom-html-parser` supplies an html5ever TreeSink over the canonical `run-dom-core::Tree`. Stable tree-local slots address parallel payloads. The sink implements text coalescing, foster-parent insertion, adoption-agency reparenting, template content fragments, namespaced attributes, document quirks mode and parser form references. Topology errors issued by the trusted tree builder are invariants; ordinary malformed HTML recovers through html5ever.

The Node-API export performs one full-document parse and encodes compact wire version two using integer sections and a deduplicated Unicode string pool. The TypeScript package validates storage, Unicode spans and graph ownership before private allocation, then exposes the stable version-one snapshot API. Node-API values own transferred storage, including the external-buffer rejection/copy fallback supplied by napi-rs. Form references are transported but the facade retains its existing form parser until association behavior is separately qualified. Script callbacks, incremental parsing, source locations and fragments are not implemented by this kernel. See `packages/html-parser/README.md` for selection, packaging, coverage and performance limits.
