# Absolute-gap optimization batch

Baseline: sealed 3xApqF. Only unchanged canonical workloads with gaps above 5 ms are targets. Cold first-use and warm batches are separate. Builds/tests never overlap timing/profiling; all comparisons use nine rotated fresh processes. Preserve selected-corpus parity, parser/default/API behavior, window isolation, mutation order, reflection, VM and lifetime contracts.

1. Cold boundaries: split the monolithic lazy CSS artifact into capability bundles, preserving CommonJS conditions and one color backend; evaluate a bundled native validation boundary to avoid first-call dependency loading. Public APIs and declared dependency ownership remain unchanged. Existing CSS/property/color/no-eval/packed-consumer tests precede comparison; cold role, first Rust document, mutation and warm role/style guards decide retention.
2. Dense wrappers: evaluate allocating native ownership slots with EventTarget objects instead of stamping them after allocation. Proxy Documents retain stamping, public prototypes/constructors/borrowed methods/structured-clone rejection remain unchanged. Existing node-storage, EventTarget, proxy/reflection/adoption and closed-handle contracts are the gates; full traversal, updates, empty windows and framework interaction guard cost shifting.
3. Role hot paths: refresh property-view attribution and evaluate direct intrinsic accessor calls versus array-producing Reflect.apply calls. Keep receiver conversion, readonly behavior, fresh snapshots, public accessor identity and foreign-window operations intact. Preserve complete CSS tests and measure role, style writes and real long-list interaction workloads.
4. Unique native parsing: separate direct native kernel/encoding, loading, checked validation and materialization costs. Evaluate transport/build changes only where attribution supports them; preserve UTF-16 offsets, Unicode bounds, exact ownership validation, parser output and actual-call counts. Native corpus, malformed boundary/no-eval tests, packed native tests and unique/warm/rotation probes decide retention.

Candidates are independent frozen source stages under `.cache/qualification/absolute-gap-*`; rejected code is removed. One combined candidate receives broad timing, memory/lifetime, real packed Vitest, fresh default/native/API/types/native corpus and complete selected-assertion gates. Document exact absolute changes and unresolved gaps; do not turn sampled profiler time into a speed ratio.

Attribution follow-ups evaluated selector-only splitting, first static query lists, one pool-wide surrogate-boundary proof, and transparent intrinsically uncloneable wrappers. All are rejected in the final source after the broad/confirmation matrix. Only native boundary packaging remains; neverthrow stays external after a built-artifact identity contract exposed its duplication. Exact default frontend artifact/source identity permits carrying forward the sealed default selected-assertion qualification; changed native boundaries receive fresh release, corpus, API, types and packed gates. The evidence and final disposition live in [absolute-gap results](absolute-gap-results.md).
