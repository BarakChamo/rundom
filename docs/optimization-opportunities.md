Staged candidates separate the mechanisms: narrower invalidation reduces the 16-operation, 8,192-row batch from 57.197 to 41.447 ms; direct traversal then reduces 41.235 to 32.395 ms in a separate paired run. These are diagnostic comparisons, not additive speed ratios.

The retained candidate preserves the weak ID map through unrelated attribute/text changes. Known structural edits invalidate IDs only in affected ordinary subtrees; ID attribute changes invalidate old/new keys. Reads repair dirty keys from current tree order, preserving first-in-tree duplicates. More than 128 outstanding keys discards the derived map and returns to ordinary admission. Unknown/parser operations retain conservative generation invalidation. Direct ID discovery and bulk indexing avoid per-node generator results; other mutation-sensitive iterators keep their contracts.

A warmed map exposed stale ID results during reentrant frame cleanup. Invalidate immediately after detachment, before cleanup reenters. Both cases have boundary tests that failed before repair.
